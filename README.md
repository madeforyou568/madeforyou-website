**Whatever the occasion, we'll make it more memorable.**

## Visual effects

The homepage includes a subtle ambient copper/gold particle layer, a native system cursor with a soft copper follow-glow, and lightweight decorative interactions. The particle layer respects `prefers-reduced-motion`, uses fewer particles on mobile, and never intercepts clicks or scrolling.

## Run locally

No build step is required. Open `index.html` in a modern browser. Keep the `assets/` and `samples/` folders beside `index.html` so the logo and sample links work.

## Deploy with GitHub Pages

1. Create a GitHub repository and upload the **contents** of this folder to the repository root.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose branch `main` and folder `/(root)`, then save.
5. Wait for GitHub Pages to publish the site; use the URL shown in Settings → Pages.
